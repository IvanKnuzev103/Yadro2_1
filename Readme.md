Теоретические проблемы с алгоритмом для бота

1 Лишние шаги: Если маршрут не продуман, еда тратится впустую на обратный путь. Лучший вариант - зайти в каждую комнату один раз по кругу и вернуться в начало, сохранив максимум припасов и потратив излишек на лучший лут в наших возмодностях.

2 Пустые комнаты: Из-за рандома может выпасть несколько пустых локаций подряд. В итоге еда закончится при этом будут взяты вещи только с некоторых не пустых комнат. Чтобы этого избежать, нужно брать лут гарантированно. Если есть возможность взять берем (жадный алгоритм)
